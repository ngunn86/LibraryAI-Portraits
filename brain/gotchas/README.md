# Gotchas found while building

The Coding Harness writes here (`harness.yaml`, `notes_writable`): one short note per surprise about the code, the libraries or Railway that a later card would want to know. For example, an OpenCV.js function that behaves differently from Python's, or a Railway setting that had to be made by hand.

One file per topic (`opencv-js.md`, `railway.md`, …), each line dated, with the card it came from.
